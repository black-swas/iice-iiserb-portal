This website is built with standard HTML headings, lists, tables, landmarks and labelled form fields, so a screen reader can move through it by heading, by landmark or by link. Each page starts with a "Skip to main content" link.

## Screen readers

These are the screen readers most people use. The website is built to work with all of them.

- NVDA, for Windows. It is free.
- JAWS, for Windows. It is paid.
- VoiceOver, for Mac, iPhone and iPad. It is built in.
- TalkBack, for Android. It is built in.

## Tips

- Use your screen reader's heading key to jump between the sections of a page.
- Use its landmark key to jump between the header, the main content and the footer.
- Press Ctrl+K (or Command+K on a Mac) to open search, then type and press Enter.

## Help

If a page does not read well with your screen reader, email iice@iiserb.ac.in and tell us which page it is and which screen reader you use.
